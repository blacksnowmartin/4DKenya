# App directory overview

This folder groups the project by feature and simulation type so the repository is easier to navigate.

## Included apps

- 4d-core: the main 4D engine API.
- defense-game: tower-defense prototype with AI-inspired state and simulation logic.
- city-nexus: city evolution and infrastructure simulation.
- network-monitor: packet and network health monitoring demo.
- network-analytics: deeper network telemetry dashboard and live analysis.
- digital-twin: city digital twin and control visualizer.
- experiments: exploratory visual effects and prototypes.

## Running a demo

Open a terminal in the folder you want to run and execute the Python file:

```bash
python game.py
```

The HTML files are companion interfaces for the main simulation and are usually opened in a browser while the FastAPI service is running locally.
